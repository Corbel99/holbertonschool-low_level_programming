# C - Recursion

## Description

This project is part of the Holberton School low-level programming curriculum.

The objective is to understand and implement recursive functions in C without using loops. Through several exercises, this project introduces the fundamental concepts of recursion, including the base case, recursive calls, and returning values.

## Learning Objectives

At the end of this project, I am able to explain:

- What recursion is.
- How recursion works.
- The importance of the base case.
- How to implement recursive functions.
- The difference between iteration and recursion.
- When recursion is appropriate.
- When recursion should be avoided.

## Requirements

- Ubuntu 20.04 LTS
- GCC
- Compilation flags:

```bash
gcc -Wall -Werror -Wextra -pedantic -std=gnu89
```

- Betty style
- No global variables
- No loops (`for`, `while`, `do...while`)
- No static variables
- Only `_putchar` is allowed for output
